School grades

Using approximate municipality averages.
How to get the file

On uddannelsesstatistik.dk → Grundskole → Karakterer, open the 9th-grade exam averages (Dyk ned i data), filter to the municipalities you care about, and export the table (… menu → Eksportér data). The file needs a column with the school name (Institution/Skole) and one with the average grade (Gennemsnit/Karakter). A municipality column (Kommune) is optional but helps. When there are several school years, the most recent is used.

The app matches school names to the schools OpenStreetMap lists inside each area. Areas with matches get their own average; others fall back to the imported municipality average.

Live data
